===========================================
## IMPLEMENTED ENDPOINTS (Current Dashboard)
===========================================

### Top Section: Daily KPI Metrics
1. GET /api/v1/analytics/dashboard/total-volume
   - Shows daily trading volume
   - Query: ?date=YYYY-MM-DD (optional, defaults to today)
   - Returns: TotalVolumeResponse {totalQuantityTraded, totalValueTraded, totalOrdersExecuted, averageOrderQuantity, averageOrderValue}
   - UI Component: KPI Card (large number display)

2. GET /api/v1/analytics/dashboard/total-trades
   - Shows daily trade counts and fulfillment metrics
   - Query: ?date=YYYY-MM-DD (optional, defaults to today)
   - Returns: TotalTradesResponse {totalTrades, filledTrades, cancelledTrades, fulfillmentRate, buyPercentage, sellPercentage}
   - UI Component: KPI Card with breakdown

3. GET /api/v1/analytics/dashboard/active-clients
   - Shows daily active client count
   - Query: ?date=YYYY-MM-DD (optional, defaults to today)
   - Returns: ActiveClientsResponse {totalActiveClients, totalClients, activeClientPercentage, activeAccounts}
   - UI Component: KPI Card with percentage indicator

### Most Active Instruments Section
4. GET /api/v1/analytics/dashboard/most-active-instruments
   - Shows top instruments for a specific date
   - Query: ?date=YYYY-MM-DD&limit=20 (optional)
   - Returns: List<InstrumentTrendResponse> {date, ticker, instrumentName, assetClass, tradeCount, totalQuantity, totalValue, uniqueTraders}
   - UI Component: Bar Chart or Table (sortable by volume/count/traders)

### Trading Volume Trends Section
5. GET /api/v1/analytics/dashboard/volume-trend
   - Shows trading volume over time for trend analysis
   - Query: ?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD (required)
   - Returns: List<VolumeTrendResponse> {date, totalQuantityTraded, totalValueTraded, tradeCount, buyCount, sellCount}
   - UI Component: Line Chart or Area Chart (time series)

### Additional Trend Analysis
6. GET /api/v1/analytics/dashboard/instrument-trend
   - Shows instrument trading trends over date range
   - Query: ?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD (required)
   - Returns: List<InstrumentTrendResponse> {date, ticker, tradeCount, totalValue, uniqueTraders}
   - UI Component: Multi-line Chart or Pivot Table

## SQL QUERY PATTERNS FOR TRENDS
===========================================

All trend queries follow this pattern:

SELECT 
  DATE(fo.created_at) as date,
  [dimension_fields],
  COUNT(*) as trade_count,
  SUM(fo.quantity) as total_quantity,
  SUM(fo.quantity * COALESCE(fo.filled_price, fo.limit_price)) as total_value,
  COUNT(DISTINCT fo.account_id) as unique_traders
FROM fact_orders fo
JOIN dim_instruments di ON fo.instrument_id = di.instrument_id
JOIN dim_accounts da ON fo.account_id = da.account_id
JOIN dim_clients dc ON da.client_id = dc.client_id
WHERE fo.status = 'FILLED' 
  AND DATE(fo.created_at) BETWEEN #{startDate} AND #{endDate}
GROUP BY DATE(fo.created_at), [dimension_fields]
ORDER BY DATE(fo.created_at) ASC, [sort_field] DESC
